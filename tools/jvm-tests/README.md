# تست منطق روی JVM (اختیاری؛ جزو بیلد Gradle نیست)
منطق بدون رابط کاربری (جست‌وجو، وضعیت آزمون، ذخیره‌سازی، بررسی فایل، پشتیبان) با شبیه‌ساز سبک اندروید (stubs) اجرا می‌شود.
- Gen19.kt با کد نسخهٔ ۱۹ فایل نمونه می‌سازد و T20.kt آن‌ها را با کد نسخهٔ ۲۰ می‌خواند (آزمون سازگاری).
- build.sh به کامپایلر Kotlin (داخل Gradle) نیاز دارد؛ مسیر LIB را در آن تنظیم کنید.
